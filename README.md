## Visão geral

O App Financeiro foi pensado para tornar o acompanhamento financeiro mais simples, organizado e privado, mantendo os dados no ambiente do usuário.

## O que o produto demonstra

- Organização de receitas e despesas.
- Acompanhamento de metas.
- Consultas e indicadores financeiros.
- Armazenamento local.
- Foco em simplicidade, clareza e privacidade.

## Fluxo de produto

```text
Lançamentos
   ↓
Organização
   ↓
Indicadores
   ↓
Decisões financeiras mais claras
```

## Privacidade

Este repositório apresenta o produto e sua proposta. O código completo e as regras internas permanecem privados. Não publique dados financeiros pessoais, bancos locais ou credenciais.
